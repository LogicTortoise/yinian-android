方案修订 / 2026 年 10 月 12 日

先把 Android 做好。

以语音闪念为入口，聚焦个人事项。原生 Android、离线可靠记录、简单清楚的行动视图。当前 HTML 仅用于评审 UI，不纳入 Web 客户端产品范围。

正式客户端建议由 React Native 改为 Kotlin + Jetpack Compose + Material 3。暂不开发 iOS、Web、桌面端，也不为了未来跨端提前引入抽象。API / MCP 保留在服务端，方便外部 Agent 接入。

建议复用底层组件，自建轻量领域模型。FullCalendar、React Flow 等 Web 组件不作为原生安卓页面依赖。第一版也先不做任意第三方视图插件运行时，内置视图共享查询与命令即可。

修订后的架构与技术栈

Android：Kotlin + Compose + Material 3
↓ ViewModel / StateFlow → 统一领域命令
本地：Room + DataStore + 录音文件 + 待同步操作队列
↓ API，同步与 AI 处理状态分离
服务端：TypeScript + Fastify + PostgreSQL + 对象存储
↓ 持久化队列 / Worker → ASR、LLM、规划、提醒
开放能力：API / MCP → 同一套权限、版本校验与领域服务
  • 本地录音和文字先保存，网络恢复后补传；AI 失败不影响闪念保留。
  • Room 保存业务记录，DataStore 保存偏好。客户端离线命令通过版本号与幂等键同步；MCP 从服务端提交修改。
  • WorkManager 用于可延迟同步和重试。提醒用 Android 通知 / 定时机制单独实现，不依赖后台任务准点唤醒。
  • 录音用 Android 平台能力；先支持前台主动录音，后台继续录音需要单独设计前台服务、权限和中断恢复。
  • 应用使用统计作为后续可选信号，需用户授权；不能凭“某应用打开多久”直接标记任务完成。

原生能力参考：Room、WorkManager、UsageStatsManager。

默认 UI 设计：氧气淡绿

2026-10-14：按本次视觉需求，将主色调整为清透的淡绿色，并增加薄表面边缘、方向性受光与分层投影。用户已确认 v4“氧气淡绿 · 轻盈浮层”为一念默认 UI 设计，后续页面与组件沿用此全局基准；历史 v3 仅作追溯参考。完整规范保存在项目根目录《UI设计规范.txt》，固定参考位于 design/reference/。

薄荷白底、深绿色正文与柔和鼠尾草绿按钮。浅蓝用于生活与时间辅助信息，浅粉用于挑战记录。卡片与主要入口有可见的薄边缘和接触阴影；视图轨道与周条使用浅凹槽衬托选中控件。按下时表面降低、阴影收紧，反馈对应其视觉高度。深色模式延续绿色材质与清楚层级，所有动效尊重减少动态效果设置。

预览会保存浏览器中的演示数据，顶部支持深浅色切换。它没有接入麦克风、AI、真实推送、账号和设备采集；排期与讨论结果使用明确标注的示例。原生组件目前完成文档与许可证筛选，尚未做 Kotlin 集成、真机性能和无障碍验证。
