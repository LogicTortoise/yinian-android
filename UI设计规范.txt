1. 设计定位

用清透的薄荷白、淡绿色与柔和立体表面，为想法提供安静的空间。
卡片有薄薄的实体边缘，按钮能够浮起和按下。
光线统一从左上方来，投影落向右下。
大面积保持低饱和度，深绿色语音入口承担全局行动重点。

预览：http://127.0.0.1:8765/?v=4#now
实现：preview/index.html、preview/styles.css、preview/app.js。
固定参考：design/reference/ 下的 v4 截图。
检查记录：preview/qa/depth-results.json。

2. 色彩

浅色主要语义色：
- 页面底色 #F2F8F5，薄荷白。
- 主表面 #FCFFFD，透白。
- 背光端 #EDF6F0，浅绿色。
- 主文字 #2E4238，深绿色；次文字 #5F7368，灰绿。
- 品牌强调 #3D6F58；强调边界 #BFD8CC。
- 浅强调表面 #E2F0E8。
- 主按钮受光端 #C0E0CD、背光端 #AFCFBF，文字 #294B39。
- 薄边缘 #D4E3DB，凹槽 #E4EEE8，分隔 #DBE7DF。
- 生活与时间辅助表面 #E9F1F7，文字 #537385。
- 挑战辅助表面 #F7EAEE，文字 #8B6172。
- 语音入口 #365E4B，主文字 #F5FFF9，辅助文字 #D8EADC。
- 浅色阴影基色 RGB(38,72,57)，高光基色 RGB(255,255,255)。

颜色按用途统一复用。浅蓝、浅粉只表达内容差异，主体保持淡绿色。
渐变描述表面的受光与背光，正文后方保持均匀、易读。

3. 表面层级

从低到高：页面底色 → 凹槽轨道 → 普通列表 → 推荐与闪念卡 → 语音入口 → 弹层。

普通列表：多行共享透白表面，2px 底边，短而弱的阴影；行内轻分隔。
推荐卡：25px 圆角，4px 暖绿底边，较宽柔和投影；主要行动优先。
闪念卡：23px 圆角，3px 底边，短接触阴影与宽柔和投影；左上缘高光。
语音入口：22px 圆角，4px 深绿底边；麦克风为凸起按键，加号为浅凹面。
主按钮：13px 圆角，3px 底边；次按钮12px圆角、2px底边。
弹层：顶部29px圆角，实色表面、顶部受光、明确的外投影与背景遮罩。

闪念卡的 CSS 阴影参考：
  0 3px 0 #D4E3DB
  0 6px 7px -4px rgba(38,72,57,0.13)
  0 17px 24px -12px rgba(38,72,57,0.22)
  inset 1px 1px 0 rgba(255,255,255,0.95)

不同高度采用不同投影距离，避免所有内容拥有相同的强调程度。

4. 控件与内容

视图切换、周日期：浅凹槽轨道，选中面有薄底边与短阴影。
分类筛选：轻量胶囊，显示真实数量；未选中保持透明。
来源图标：31px 视觉尺寸、11px 圆角的小凸起表面，区分文字与语音。
导航：四个入口稳定，透白轨道23px圆角，选中图标轻浮起。

闪念信息顺序：来源与时间 → 标题 → 原文摘要 → 分类与模式 → 详情提示。
整张卡片可进入详情。摘要展示两行，详情保留全文。
数量、状态和录入来源取自数据。语音与 AI 仍明确标注为交互演示。

5. 字体与间距

使用中文无衬线与系统字体回退，数字采用等宽数字。
- 页面标题31px / 650，极窄屏27px。
- 推荐标题21px / 550，极窄屏19px。
- 闪念标题16px / 600，行高1.55。
- 摘要12px，行高1.85。
- 来源、时间、分类、模式与计数10px。
- 水平内容边距23px，极窄屏18px。
- 闪念卡内距17px 18px 12px，卡片间距18px。

原生落地保留相对层级，用 dp/sp 实现；辅助小字、触控区域与系统大字体需结合真机放大。

6. 按压反馈

主按钮按下向下2px，底边缩为1px并收紧阴影。
语音胶囊按下向下3px，底边缩为1px。
闪念卡按下向下2px并缩为0.99，收紧投影。
支持指针的设备，悬停卡片上移2px，投影展开。
常规反馈180ms；视图指示器240ms；弹层进入180ms。
不添加循环装饰动画。减少动态效果设置关闭非必要动画与过渡。
键盘焦点保留明确的强调色轮廓。

7. 深色模式

页面 #1B2822，主表面 #26362D，背光端 #22332A。
主文字 #EAF5EE，次文字 #B3C7BB，强调 #A3D7BA。
凹槽 #18271F，薄底边 #17281D，边界 #3D5446。
高光基色 RGB(71,100,82)，保持克制的绿色层次。
语音入口 #B8DCC8，主文字 #203F2D，辅助文字 #486553。
浅蓝与浅粉语义继续保留，通过表面明度、薄边缘和微弱高光表达高度。

8. 页面与预览

现在：单一推荐卡为主要内容，后续事项使用低层级分组列表。
闪念：浮起卡片保留原话，浅凹槽与轻筛选帮助回看。
计划：周日期选中项为实体按钮，日程块有薄边缘，留白保持轻量。
我的：偏好按组共享透白表面，组内分隔，头像轻凸起。
录入与专注：遵循弹层和按钮材质；计时器为圆形实体表面。

桌面预览增加柔和展台与机框侧边；正面保持正视便于交互。
470px及以下直接显示应用，移除展台和机框。

已在 Chrome 中检查四个页面的320、360、412宽度，无横向溢出。
